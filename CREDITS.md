## Source availability (GPL compliance for the ISO)

The PMX OS ISO redistributes GPL/LGPL binaries that come **from Debian**. The complete,
corresponding source for every such package is available from the Debian archive — this is how
Debian derivatives satisfy the GPL's source‑availability requirement:

- `apt-get source <package>` on a Debian system, **or**
- the Debian source mirrors: <https://deb.debian.org/debian/> (`deb-src`), **and**
- historical/exact versions via Debian snapshots: <https://snapshot.debian.org/>

No GPL component in PMX OS is modified from its Debian package; only configuration, theming, and
branding are added (all of which live in this repository).
